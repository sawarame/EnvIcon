# EnvIcon 詳細仕様書 (Feature Specifications)

このドキュメントは、EnvIconの各機能の詳細な振る舞いや内部仕様を記述するファイルです。
機能を追加・改修する際（特にAIにコード変更を依頼する際）には、必ずこの仕様書の内容に沿って実装を行ってください。また、仕様が変わる場合はこのドキュメントも更新してください。

---

## 1. 全体アーキテクチャとデータ構造

_※ここに全体のデータの持ち方（chrome.storageのスキーマなど）を記載します_

- **Chrome Storage (`sync`)**:
  - `environments` (EnvironmentConfig[]): 各環境の定義をまとめた配列。各要素は以下のプロパティを持つ:
    - `id` (string): 環境識別子。デフォルト環境は `"prod"` `"stg"` `"dev"` 、ユーザー作成は `"custom_<timestamp>"` 形式。
    - `name` (string): 画面に表示される環境名。
    - `badgeText` (string): バッジの表示文字（最大4文字）。
    - `badgeColor` (string): バッジの文字色（HEX形式）。
    - `badgeOutlineColor` (string): バッジのフチドリ色（HEX形式）。
    - `faviconEnabled` (boolean): Favicon書き換え機能の環境ごとのON/OFF。デフォルト`true`。
    - `pageBadgeEnabled` (boolean): ページ内バッジ表示機能の環境ごとのON/OFF。デフォルト`true`。
    - `pageBadgePosition` (string): ページ内バッジの表示位置。`'top-left'` | `'top-right'` | `'bottom-left'` | `'bottom-right'` のいずれか。デフォルトは `'bottom-right'`。
    - `pageBadgeFontSize` (number): ページ内バッジの文字サイズ（px）。デフォルトは `24`。
    - `hostnames` (HostnamePattern[]): 環境判定に使用するホスト名または正規表現パターンの配列。
    - `isDeletable` (boolean): `true` の場合、ユーザーを削除可能。PROD/STG/DEVは `false` 。
- **Chrome Storage (`local`)**:
  - `language` (string): 全体設定の表示言語（`"en"` または `"ja"`）。ブラウザごとに保存される。
  - `darkMode` (boolean): ライト・ダークモードの表示設定。ブラウザごとに保存される。
- **Chrome Storage (`session`)**:
  - ブラウザ起動中のみ保持され、Chrome 再起動時に自動クリア（ON状態へ自動復帰）される一時OFF用のデータ領域（`TRUSTED_AND_UNTRUSTED_CONTEXTS` アクセスレベルで構成）。
  - `globalDisabled` (boolean): `true` の場合、拡張機能全体（全サイト）でバッジ表示を一時的に無効化する。
  - `disabledHostnames` (string[]): サイト（ホスト名）単位で一時的に無効化しているホスト名（小文字）の配列。

## 2. 各機能の詳細仕様

### 2.1 Faviconの動的書き換え機能 (`src/features/favicon_changer.ts`)

- **概要:** 現在開いているタブのURLがオプションで設定された任意の環境のホストに一致する場合、Faviconに環境を示すバッジを重ねて表示する。`environments` 配列を先頭から順にループし、最初に一致した環境の設定が適用される。
- **データフロー:**
  1. `content.ts` がページロード時に初期化される。
  2. Storageから現在の設定情報を取得し、現在のURLとマッチするか判定する。
  3. マッチした場合、元のFavicon画像をCanvas等で読み込み、ラベルや色を重ねてData URIを生成し、`<link rel="icon">` や `<link rel="shortcut icon">` を更新する。
- **エッジケース（考慮事項）:**
  - 元のページのFaviconが存在しない場合のフォールバックの挙動。
  - **動的なFavicon更新への対応**:
    - `MutationObserver` を用いて、`<head>` 内の要素追加（`childList`）だけでなく、既存のfaviconタグの `href` や `rel` 属性の変更（`attributes`）も監視し、サイト側での書き換えを検知して再適用する。
    - Observerをすり抜ける特殊な書き換えへの対策として、`setInterval` による定期チェック（3秒おき）を併用する。
    - **堅牢性の向上**:
      - `MutationObserver` による変更検知時、自ら無効化した既存のfaviconタグを無視せず、元のURLを維持したまま再評価を行う。
      - DOM内にfaviconが見つからない場合、`chrome.tabs` API（バックグラウンド経由）からブラウザが検出済みの `favIconUrl` を取得して補完する。
      - リダイレクトやSPA（Single Page Application）での遷移に対応するため、読み込み失敗時（白背景フォールバック時）はキャッシュせず、正しいfaviconが取得できるまで再試行を許可する。
      - 非同期処理の競合を防ぐため、リクエストIDによる世代管理を行い、最新の描画結果のみを適用する。
    - 無駄な再描画を避けるため、最後に適用したData URIや元のソースURLを保持し、変化がない場合は処理をスキップする最適化を行っている。
  - **リアルタイム更新と元Faviconの復元**:
    - `chrome.storage.onChanged` で `sync` および `session` ストレージの変更を監視し、ポップアップや設定画面での操作をページリロードなしで即座に反映する。
    - 一時OFFへの切り替えや環境登録解除時には、生成したカスタム `<link>` を除去するとともに、無効化していたサイト本来の `<link>` 属性（`rel` および `disabled`）を元の状態に復元する（もともと `<link>` タグを持たないサイトでは元のファビコンURLを復元適用する）。

### 2.2 オプション設定画面 (`src/options.ts`, `package/options.html`)

- **概要:** ユーザーが対象環境のホスト名や正規表現パターンを設定する画面。Bootstrap 5ベースで構築されている。
- **機能・UI仕様:**
  - **全体設定**:
    - 画面右上に**ダークモード切り替えボタン**を持たせ、クリックでライト・ダークモードを切り替え可能。設定は `chrome.storage.local` に保存され、初期化時にシステムのテーマ設定をデフォルトとして適用する。
    - 画面右上のハンバーガーメニュー内の**言語切り替えサブメニュー**から、英語（en）と日本語（ja）を瞬時に切り替え可能。選択した言語は `chrome.storage.local` に保存され、ブラウザごとのデフォルト言語として復元される。
  - **環境ごとのリスト設定とバッジカスタマイズ**:
    - **ユーザーによる環境追加・削除**: 画面下部の「環境追加（+ Add Environment）」ボタンを押すとダイアログが表示され、環境名を入力することで新しい環境ブロックが追加される。ユーザーが作成した環境は「環境を削除」ボタンで削除できる。
    - **削除時の確認**: ユーザー作成環境を削除する際は、誤操作防止のため確認ダイアログ（Confirmation Modal）を表示する。
    - **デフォルト環境（PROD/STG/DEV）の保護**: `id` が `"prod"` `"stg"` `"dev"` の環境は削除不可（`isDeletable: false`）。
    - **環境名の編集**: カスタム環境では、環境名の左側に配置された**鉛筆アイコン**をクリックすることで、環境名入力フィールドにフォーカスを当てて編集できる。
    - **バッジ設定**: ファビコンに重ねて描画される「文字列（最大4文字）」「文字色」「フチドリ色（Outline）」をカスタマイズできる。
    - **環境ごとの機能トグル**: 各環境カードに「Favicon書き換え」「ページ内にバッジを表示」「開発者ツール（コンソール）に表示」のトグルを配置。トグル行は 100% 幅で均一に配置される。
    - **リセットボタン（Reset）**: 各環境のバッジを環境ごとの初期設定値にワンクリックで戻せる。
    - 各環境ごとにホスト名の入力フィールドを複数追加・削除できるリストUIを持つ。
    - **ドラッグ＆ドロップ**: 各入力フィールドの左端にあるハンドル（⋮⋮）を掴んで、リストの並び順を変更可能。
    - **入力方式（正規表現対応）**:
      - 通常のホスト名入力（例: `example.com`）が基本。
      - `Regex` チェックボックスをONにすることで、正規表現によるパターン入力（例: `^.*\.local$`）への切り替えが可能。
    - **削除制約**: セクションごとに最低1つの入力欄を維持するため、最後の1つのフィールドは削除できない（Removeボタンが無効化される）。
  - **自動保存（オートセーブ）とバリデーション**:
    - **自動保存（オートセーブ）**: 手動の `Save` ボタンは廃止され、設定変更時に自動的に保存される。フッターには「環境追加」ボタンと「自動保存ステータスインジケーター」が配置される。
    - **デバウンス処理**: テキスト入力やトグル切り替えなどの変更を検知すると、500msのデバウンスタイマーが作動し、入力完了後にまとめて保存処理が実行される（Storage Sync APIの書き込み制限対策および入力途中のエラー防止）。
    - **ステータス表示**:
      - 変更検知〜保存中: 「保存中...」（ローディングスピナー）
      - 保存完了: 「すべての変更を自動保存しました」（緑のチェックアイコン）
      - バリデーションエラー時: 「入力内容に不備があるため保存されていません」（注意アイコン）
    - **バリデーションルール**:
      - **環境名**: 空文字（スペースのみ含む）ではないこと。
      - **ホスト名/パターン**: 通常のホスト名として有効、または正規表現がパース可能であり、環境間を含めて重複がないこと。
      - **カラー設定（文字色・フチ色）**: `#FFF` や `#FFFFFF` のような有効なHEX形式（3桁、4桁、6桁、8桁）であること。
      - **文字サイズ**: ページ内バッジ表示が有効な場合、空欄ではなく 1〜500 の範囲の数値であること。
    - 不正な入力や重複がある場合、保存は保留され該当フィールドが赤枠（`p-invalid`）で強調される。ユーザーが修正して正しい値になった時点で自動的に保存が完了する。
    - **即時保存**: ウィンドウの離脱時（`beforeunload`）、ショートカットキー（`Ctrl+S` / `Cmd+S`）、設定ファイルのインポート完了時にはデバウンスを待たずに即時保存が実行される。

### 2.3 ページ内バッジ表示機能 (`src/features/page_badge_changer.ts`)

- **概要:** `pageBadgeEnabled` が `true` のとき、現在開いているタブのURLがオプションで設定された環境のホストに一致する場合、ページ本文の固定位置にバッジテキストを表示する。
- **表示仕様:**
  - ページ内の `<body>` 要素に `id="env-icon-page-badge"` の `<div>` を追加する。
  - スタイルは `position: fixed`、`z-index: 2147483647`（最前面）、`pointer-events: none`。
  - 文字は `font-weight: bold`（ボールド）、`opacity: 0.5`（半透明）。
  - `pageBadgePosition` の値に従い、左上・右上・左下・右下に配置する（デフォルトは右下）。
  - `pageBadgeFontSize`（デフォルト24px）で文字サイズを制御する。
  - `badgeColor` を文字色に使用し、`badgeOutlineColor` を `text-shadow` で枠として使用する。
  - バッジのテキストは `badgeText` を大文字で表示する。
- **ON/OFFの制御:** 環境の `pageBadgeEnabled` が `false` の場合、一時OFF（全体OFFまたはサイト単位OFF）が有効な場合、またはURLに一致する環境がない場合は、既にDOMに存在するバッジ要素を即座に除去する。`chrome.storage.onChanged` によりリロード不要でリアルタイム反映される。

### 2.4 開発者ツールとの連携 (`src/features/console_logger.ts`)

- **概要:** `consoleLogEnabled` が `true` のとき、現在開いているタブのURLがオプションで設定された環境のホストに一致する場合、ブラウザのコンソールに環境情報を表示する。
- **表示仕様:**
  - `[EnvIcon] Current Env: <環境名>` という形式でログを出力する。
  - テキストの色は `badgeColor` を使用し、太字で表示する。
  - 視認性向上のため、`badgeOutlineColor` を使用した `text-shadow` を適用する。
- **ON/OFFの制御:** 環境の `consoleLogEnabled` が `false` の場合、またはURLに一致する環境がない場合はログを出力しない。デフォルトは `true`（有効）。

### 2.5 拡張機能アイコンのバッジ表示 (`src/background.ts`)

- **概要:** ブラウザのツールバーに表示される拡張機能アイコン自体に、現在の環境や一時OFF状態を示すバッジを動的に描画する。
- **表示仕様:**
  - `OffscreenCanvas` を用いてベースアイコン上に最大4文字の `badgeText`（または `id`）を `badgeColor`（文字色）・`badgeOutlineColor`（フチドリ色）で描画し、`chrome.action.setIcon` でタブごとに適用する。
  - **一時OFF中のミュート表示:** 全体一時OFF中、または現在のタブのホスト名がサイト単位の一時OFF対象になっている場合は、ベースアイコンをグレースケール＋半透明に変換した上で `"OFF"` インジケーターを重ねて描画し、一時OFF中であることがツールバー上で一目で判別できるようにする。
- **更新タイミング:**
  - タブのURLや読み込み状態が更新されたとき（`chrome.tabs.onUpdated`）。
  - アクティブなタブが切り替わったとき（`chrome.tabs.onActivated`）。
  - 環境設定（`sync`）または一時OFF設定（`session`）が変更されたとき（`chrome.storage.onChanged` で全タブを一括更新）。
- **ON/OFFの制御:** 通常動作時で一致する環境がない場合、または対象外URL（`chrome://` など）の場合はデフォルトのカラーアイコンに戻す。

### 2.6 設定のインポート/エクスポート機能

- **概要:** チーム間での設定共有を容易にするため、現在の環境設定をJSON形式で書き出し（Export）、またはJSONファイルから読み込み（Import）して一括反映する機能。
- **仕様:**
  - オプション画面の右上のハンバーガメニューに「Export Settings」「Import Settings」のアクションを配置。
  - Export時は現在の環境設定（`environments`配列）をJSON形式にし、`EnvIcon_YYYYMMDDHHMMSS.json` というファイル名でダウンロードさせる。
  - Import時は選択されたJSONファイルを読み込み、フォーマット（配列かどうか等）を検証する。フォーマットが不正な場合はエラーを提示し処理を中断、正しければ現在のUIのデータを置き換える。さらに保存ボタンが押されることで `chrome.storage.sync` を上書きする。

### 2.7 クイック操作ポップアップ (`src/popup.ts`, `src/popup/PopupApp.vue`, `package/popup.html`)

- **概要:** ツールバーの拡張機能アイコンをクリックした際に開くコンパクトなポップアップ画面。設定画面を開かずに日常的な環境割り当てや一時OFF（ミュート）を素早く行える。
- **機能・UI仕様:**
  - **ヘッダー＆基本導線:**
    - **全体ON/OFFマスタースイッチ:** 全サイトのバッジ表示を一括で一時OFF / ON に切り替える。全体一時OFF中はポップアップ内およびオプション設定画面上に通知バナーを表示する。
    - **設定画面ショートカット:** 右上の歯車ボタン（および拡張機能アイコン右クリックの「オプション」メニュー）から `options.html` を開く。
    - **テーマ・言語連動:** `chrome.storage.local` の `darkMode` と `language` を参照し、オプション画面と統一されたテーマ・言語で表示する。
  - **現在のサイト情報 ＆ サイト単位の一時OFF:**
    - アクティブタブのホスト名と現在のステータス（環境バッジ / 未登録 / 一時OFF中）を表示する。`http:` / `https:` 以外のページや Chrome ウェブストア等の制限ページでは「利用不可」と案内しサイト別操作を無効化する。
    - **「このサイトを一時OFF」トグル:** 設定データ（`environments`）を変更することなく、現在のホスト名のみバッジ表示を一時停止する。
    - **戻し忘れ防止:** 全体OFF・サイト単位OFFともに `chrome.storage.session` に保存され、リロードや別タブ移動では維持しつつ、Chrome 再起動時に自動的にONへ復帰する。
  - **ワンクリック環境登録・変更・解除:**
    - `PROD` / `STG` / `DEV` およびカスタム環境をカラーバッジ付きボタン一覧として表示し、クリック1回で現在のホスト名を即座に割り当て・別環境へ移動できる。
    - すでに割り当て済みの環境ボタンを再クリックするか「登録解除」ボタンを押すことで、その場ですぐ登録を解除できる。
    - **正規表現（Regex）一致時の保護:** 正規表現パターンによって一致しているサイトでは、誤って他のサブドメインを含むパターンを破壊しないよう一致パターンを表示して変更・解除をロックし、編集は設定画面へ誘導する（一時OFFトグルは利用可能）。

## 3. 将来の拡張構想 (Future Plans)

現在計画されている、今後実装予定のエンハンスメントは以下の通りです。

2. **プリセットライブラリ**: AWS、GCP、Azure、GitHubなど、一般的なサービスのデフォルトURLパターンのプリセット提供。
3. **バッジ形状のカスタマイズ**: 四角形だけでなく、円形、角丸、または特定のアイコン（鍵マークなど）をオーバーレイする機能。
5. **環境グループ化機能**: プロジェクトごとに環境をグループ化し、一括で表示/非表示を切り替える機能。
6. **CSP (Content Security Policy) 制限への対策**: サイト側で `img-src data:` が制限されている場合でもバッジを表示可能にする手法の検討。
7. **アニメーションFaviconへの対応**: GIFなどの動くFaviconに対しても、アニメーションを維持したままバッジを重畳する機能。
8. **透過背景のFaviconでの視認性向上**: 元のFaviconが透明な場合に、バッジの背後を適宜塗りつぶすなどして視認性を確保する改善。
9. **環境セクション自体の並び替え機能**: 現在のホスト名単位の並び替えに加え、環境ブロック（PROD/STG等）自体の優先順位をドラッグ＆ドロップで変更できる機能。
10. **`<all_urls>` 権限の最小化**: セキュリティ向上のため、全URLへのアクセス権限をデフォルトで要求せず、ユーザーが指定したサイトにのみ動的に権限を要求する（Optional Permissions）方式への変更。
