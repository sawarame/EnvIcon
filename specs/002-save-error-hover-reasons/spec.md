# 機能仕様書: 保存エラー表示時のマウスオーバーによる不備理由表示

**Feature Branch**: `002-save-error-hover-reasons`

**Created**: 2026-11-07

**Status**: Draft

**Input**: User description: "「入力内容に不備があるため保存されていません」が表示された時にマウスオーバーで不備の理由を表示するようにしたい。"

## Clarifications

### Session 2026-11-07

- Q: 不備が多数発生した際、吹き出しのマウスオーバー挙動と表示件数の扱いはどの方式にしますか？ → A: 吹き出し上へカーソルを移動しても表示を維持し、一定の高さを超える場合は吹き出し内でスクロールして全件表示する（保存エラー表示と吹き出しの両方からカーソルが離れたら閉じる）。
- Q: URLパターンや正規表現パターンが重複している場合、不備理由にはどこまでの情報・対象を含めますか？ → A: 後発の重複行をエラー項目（赤枠強調と一致）としつつ、理由文に重複相手の環境名（または同一環境内での重複である旨）を含めて表示する。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 保存エラー表示へのマウスオーバーによる不備箇所と理由の即時確認 (Priority: P1)

オプション設定画面で設定を編集中に「入力内容に不備があるため保存されていません」（英語表示時は対応するエラーメッセージ）が画面下部の保存ステータスに表示された際、ユーザーがそのメッセージ領域にマウスカーソルを重ねるだけで、画面を上下にスクロールして探し回ることなく「どの環境の・どの項目が・どのような理由で不備になっているか」をその場で即座に確認できる。

**Why this priority**: 複数の環境セクションが縦に並ぶ設定画面において、どの入力値が原因で自動保存が保留されているのかをひと目で特定できるようにすることが本機能の中核価値であるため。

**Independent Test**: オプション設定画面でいずれかの環境に不正な入力（例：不正なURLパターンや空欄の環境名）を行って保存エラー表示を発生させ、フッターの保存エラー表示にマウスカーソルを重ねた際に該当環境名と具体的な不備理由が表示され、カーソルを外すと非表示になることで単独検証できる。

**Acceptance Scenarios**:

1. **Given** オプション設定画面の保存ステータスに「入力内容に不備があるため保存されていません」が表示されている状態、**When** ユーザーがその保存エラー表示（警告アイコンまたはテキスト）にマウスカーソルを重ねる、**Then** 画面下部で見切れることなく、不備が発生している環境名と具体的な不備理由が吹き出しとして表示される。
2. **Given** 不備理由の吹き出しが表示されている状態、**When** ユーザーが吹き出し上にカーソルを移動する、**Then** 吹き出しの表示は維持され、保存エラー表示領域および吹き出しの双方からマウスカーソルを外した時点で速やかに非表示になる。
3. **Given** 保存ステータスが「すべての変更を自動保存しました」または「保存中...」の正常状態、**When** ユーザーが保存ステータス表示にマウスカーソルを重ねる、**Then** 不備理由の吹き出しは表示されない。

---

### User Story 2 - 複数不備の一覧把握と修正・取り消し操作へのリアルタイム追従 (Priority: P2)

1つの環境内または複数の環境にまたがって複数の入力不備（環境名の未入力、バッジ色の形式不備、文字サイズの範囲外、通常URLパターンの形式不備、正規表現の構文エラー、パターンの重複）が同時に発生している場合でも、すべての不備理由を一覧で漏れなく確認でき、不備を1つずつ修正したり「編集内容を取り消す」・環境削除を行ったりするたびに表示内容が最新状態へ自動更新される。

**Why this priority**: 複数の項目を連続編集した際や重複パターンが発生した場面で、一度の確認ですべての修正対象を把握し、解消済みのエラーに惑わされることなくスムーズに全件解決できるようにするため。

**Independent Test**: 2つ以上の異なる環境にそれぞれ別種類の不備（例：カスタム環境の環境名空欄と、本番環境のURLパターン重複）を発生させ、マウスオーバー時に両方の不備理由が一覧表示されること、および片方を修正または取り消しすると残りの不備のみに更新されることで単独検証できる。

**Acceptance Scenarios**:

1. **Given** 複数の環境または複数項目に同時に不備（例：環境名未入力、不正なカラーコード、重複するURLパターン）が存在する状態、**When** 保存エラー表示にマウスカーソルを重ねる、**Then** 発生しているすべての不備が環境名と項目・理由（パターン重複時は重複相手の環境名または同一環境内重複である旨を含む）の組み合わせで漏れなく一覧表示される。
2. **Given** 複数の不備が発生している状態、**When** ユーザーがそのうち1つの不備を修正して再検証が行われる、**Then** マウスオーバー時に表示される不備理由の一覧から解消済みの項目が取り除かれ、未解消の不備理由のみが表示される。
3. **Given** 不備が発生して保存エラー表示になっている状態、**When** ユーザーが該当環境の「編集内容を取り消す」操作または環境削除を行ってすべての不備が解消される、**Then** 保存エラー表示自体が解消されて通常の保存完了状態へ復帰し、マウスオーバーしても不備理由は表示されない。

### User Story 3 - 表示言語およびライト・ダークテーマに応じた視認性の確保 (Priority: P3)

利用者の表示言語設定（日本語・英語）や画面テーマ設定（ライトモード・ダークモード）にかかわらず、不備理由の説明文が選択中の言語で自然に表示され、背景と文字の十分なコントラストが保たれる。また、保存エラー表示にマウスオーバーできることを示す視覚的な手がかりにより、詳細理由を確認できることに迷わず気づける。

**Why this priority**: 日英両言語およびライト・ダーク両テーマをサポートする設定画面全体の一貫した操作体験と発見しやすさを維持するため。

**Independent Test**: 保存エラー発生中に表示言語を日本語と英語で切り替え、さらにライトモードとダークモードを切り替えてマウスオーバーした際、それぞれの言語とテーマに適した視認性の高い表示になることで単独検証できる。

**Acceptance Scenarios**:

1. **Given** 保存エラーが発生している状態、**When** 表示言語を日本語から英語（または英語から日本語）へ切り替えて保存エラー表示にマウスカーソルを重ねる、**Then** 環境名および不備理由の説明文がすべて選択中の言語で表示される。
2. **Given** ライトモードまたはダークモードが選択されている状態、**When** 保存エラー表示にマウスカーソルを重ねる、**Then** カーソル形状の変化等によって詳細確認が可能であることが分かり、選択中のテーマに応じた配色で文字が明瞭に判読できる。

---

### Edge Cases

- カスタム環境の「環境名」自体が空欄（または空白のみ）になっている場合は、不備理由の対象環境名として空文字を表示するのではなく、「（名称未設定の環境）」のように識別可能な代替名称を用いて環境名未入力や他項目の不備を表示する。
- 複数行・複数環境にわたって多数の不備（例：10件以上）が同時に発生している場合でも、吹き出し上へカーソルを移動して内部を縦スクロール操作できるようにし、画面外へはみ出すことなく全件を閲覧可能にする。
- 不正または重複したURLパターン・正規表現パターンに非常に長い文字列が入力されている場合でも、吹き出しの横幅が過度に広がったりレイアウト崩れを起こしたりしないよう、適切な折り返しまたは省略表示によって判読可能に保つ。
- ページ内バッジ表示がOFF（無効）になっている環境の「文字サイズ」欄など、保存検証の対象外となっている項目については不備理由として含めない。
- 残っていた最後の不備を「編集内容を取り消す」操作等で解消し、設定内容が直前の保存済み状態と同一に戻った場合でも、保存エラー表示が残留せず正常な保存済みステータスへ確実に復帰する。
- 無効化（OFF）されているパターン行に不正な形式や重複するパターンが含まれている場合は、既存の保存検証ルールと完全に一致する基準でエラー有無を判定し、画面上の赤枠強調と不備理由一覧の間で食い違いが生じないようにする。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、オプション設定画面の保存ステータスが入力不備による未保存エラー状態（「入力内容に不備があるため保存されていません」および対応する英語文言）にあるとき、その保存エラー表示領域（アイコンおよびテキスト）へのマウスオーバー操作によって現在発生している不備の理由を表示しなければならない（MUST）。
- **FR-002**: システムは、保存ステータスが「保存中」または「自動保存完了」などのエラー以外の状態にあるときは、保存ステータス領域にマウスオーバーしても不備理由の吹き出しを表示してはならない（MUST NOT）。
- **FR-003**: システムは、自動保存を保留させる全7種類の検証エラーについて、ユーザーが修正対象と原因を理解できる具体的な不備理由を判別・提示しなければならない（MUST）。対象となる不備種別は以下の通りとする：
  - 環境名が未入力（空欄または空白のみ）
  - バッジの「色」のカラーコード形式が不正
  - バッジの「フチ色」のカラーコード形式が不正
  - ページ内バッジ有効時における「文字サイズ」が未入力または有効範囲外
  - 通常モードのURL・ホスト名パターン（ホスト名やポート番号等）の形式が不正
  - 正規表現モードのパターンにおける正規表現の構文エラー
  - URLパターンまたは正規表現パターンの重複（同一環境内および異なる環境間の重複を含む）
- **FR-004**: 各不備理由の表示には、不備が発生している「対象の環境名」と「具体的な不備内容（対象項目およびエラー理由）」を含めなければならない（MUST）。URLパターンや正規表現パターンの不備・重複については該当する入力値（または行位置情報）を併記し、特にパターン重複エラーについては既存の赤枠強調と一致する後発の重複行をエラー項目とした上で、異なる環境間での重複時は重複元の環境名を、同一環境内での重複時は同一環境内での重複である旨を理由文に含めなければならない（MUST）。
- **FR-005**: カスタム環境の環境名が未入力である場合、不備理由に表示する環境名には空文字ではなく「名称未設定」を示す識別可能な代替ラベルを使用しなければならない（MUST）。同一の環境で環境名未入力と他項目の不備が同時に発生している場合も、同じ代替ラベルを用いて一貫して表示しなければならない（MUST）。
- **FR-006**: 複数の不備が同時に発生している場合、システムは画面上の環境の並び順（上から順）および環境内の設定項目順に従って、発生中のすべての不備理由を一覧形式で整理して表示しなければならない（MUST）。
- **FR-007**: 不備理由の吹き出しは、画面下部の固定フッター付近でマウスオーバーした際にもブラウザの表示領域外へ見切れない位置（原則として保存エラー表示の上方）に表示しなければならない（MUST）。また、保存エラー表示領域または吹き出し自体のいずれかにマウスカーソルがある間は表示を維持して双方からカーソルが離れた時点で閉じるものとし、一定の高さを超える件数の不備がある場合でも吹き出し内の縦スクロール操作によって画面内に収めたまま全件を確認できなければならない（MUST）。
- **FR-008**: ユーザーが入力値の修正、パターン行の削除、環境の削除、または「編集内容を取り消す」操作を行った際、システムは不備理由の一覧および保存ステータスを即座に再評価・更新し、すべての不備が解消された時点で（直前の保存済み状態と同一に戻った場合を含め）保存エラー表示および不備理由表示を解除しなければならない（MUST）。
- **FR-009**: 保存エラー表示領域は、マウスオーバーによって詳細理由を確認できることを示す視覚的な手がかり（カーソル形状の変化や情報アイコン等）を備えなければならず（MUST）、キーボード操作によるフォーカス時にも同等の不備理由を確認できるようにしなければならない（MUST）。
- **FR-010**: 不備理由に関するすべての表示テキスト（各エラー理由の文言、重複相手の環境表示、未入力環境名の代替ラベル等）は日本語および英語の双方に対応し、現在選択されている表示言語および画面テーマ（ライトモード・ダークモード）に連動して表示されなければならない（MUST）。

### Key Entities

- **保存検証エラー項目 (Validation Error Item)**: 自動保存が保留される原因となっている個別の入力不備を表す情報。対象環境の識別子・表示名（名称未入力時の代替名を含む）、不備が発生している項目区分、エラー理由の種別（未入力・形式不正・範囲外・構文エラー・重複）、パターン不備時の対象入力文字列、および重複エラー時の競合先情報（重複元の環境名または同一環境内重複の区別）を持つ。
- **保存ステータス表示 (Save Status Indicator)**: オプション設定画面下部に常駐し、現在の自動保存状態（保存完了・保存中・入力不備による未保存）を利用者へ伝える状態表示領域。未保存エラー状態においてのみ、現在発生している「保存検証エラー項目」の一覧をマウスオーバーおよびフォーカス時の詳細情報として提示する。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーは、オプション設定画面で保存エラーが表示された際、画面をスクロールして全環境カードを目視確認することなく、保存エラー表示へのマウスオーバー操作から 3秒以内に「どの環境の・どの項目が・なぜ保存できないのか（重複時はどの環境と競合しているかを含む）」を特定できる。
- **SC-002**: オプション設定画面で発生し得る全7種類の入力不備（環境名未入力、文字色不正、フチ色不正、文字サイズ範囲外、URLパターン形式不正、正規表現構文エラー、パターン重複）について、単独発生時および複合発生時のいずれにおいても 100% 漏れなく対応する不備理由が表示され、各入力欄のエラー強調状態と完全に一致する。
- **SC-003**: 入力修正・「編集内容を取り消す」・パターン行削除・環境削除によって不備が解消された際、自動保存の再評価完了と同時に不備理由リストの更新または保存エラー状態の解除が反映され、解消済みエラーが残り続ける事象の発生件数が 0件となる。
- **SC-004**: 日本語・英語の両表示言語、およびライトモード・ダークモードの両テーマにおいて、不備件数が1件の場合から10件以上の複数同時発生時まで、画面外への見切れや文字の判読不能を生じることなく吹き出し内スクロールを含めて全件を確認できる。

## Assumptions

- 本機能の対象はオプション設定画面下部の固定フッター内にある保存ステータスメッセージ領域とし、各入力フィールドにおける既存の赤枠エラー強調表示はそのまま維持・併用する。
- 不備理由の吹き出しは閲覧専用の案内表示とし、吹き出し内での直接編集機能や該当箇所への自動スクロールジャンプ機能は本スコープの必須要件には含めない。
- 各設定項目の有効値・検証ルール自体（カラーコードの許容桁数、文字サイズの許容範囲、URLパターンの正規化および重複判定基準）は既存の仕様をそのまま継承し、本機能の追加によって既存の有効な設定データが新たにエラー扱いになることはない。
