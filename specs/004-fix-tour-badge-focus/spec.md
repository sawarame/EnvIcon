# Feature Specification: ヘルプツアーにおける「バッジのカスタマイズ」タブ自動切替とフォーカス復元

**Feature Branch**: `004-fix-tour-badge-focus`

**Created**: 2026-11-16

**Status**: Draft

**Input**: User description: "この拡張機能のヘルプツアーの「バッジのカスタマイズ」ですが、以前タブ化した影響か、どこにもフォーカスされなくなってしまっております。ちゃんとタブを切り替えてカスタマイズ項目にフォーカスされるようにしてもらえますか。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 「バッジのカスタマイズ」ステップでの自動タブ切替と設定項目フォーカス (Priority: P1)

ユーザー（新規利用者や設定手順を確認したい利用者）が設定画面でヘルプツアーを開始し、「バッジのカスタマイズ」ステップに進んだ際、対象環境カードの「デザイン・表示設定」タブが自動的に選択されて表示され、バッジの文字や色をカスタマイズできる「バッジ設定」エリアが確実にハイライト表示される。案内用の吹き出しもその設定エリア付近に配置されるため、ユーザーはどの項目を変更すればよいかを迷わず直感的に理解できる。

**Why this priority**: 現在のヘルプツアーでは対象の設定項目が非表示タブ内に隠れているためフォーカスが外れてしまい、ツアーの案内と画面表示が一致していない。本機能の核心である「機能へのフォーカス案内」を回復することが最優先であるため。

**Independent Test**: 対象環境カードが「URLパターン」タブを開いた初期状態からヘルプツアーを開始し、「バッジのカスタマイズ」ステップへ進んだ際に「デザイン・表示設定」タブへ切り替わり、「バッジ設定」エリアがハイライトされることで独立して検証できる。

**Acceptance Scenarios**:

1. **Given** 対象環境（本番環境）カードで「URLパターン」タブが表示されている状態でユーザーがヘルプツアーを開始した時、**When** 「バッジのカスタマイズ」ステップに進むと、**Then** 対象環境カードが「デザイン・表示設定」タブへ自動的に切り替わり、「バッジ設定」エリア（バッジの文字・文字色・枠線色を含む項目群）がハイライトされ、その付近に案内吹き出しが表示される。
2. **Given** 対象環境カードで「デザイン・表示設定」タブがすでに表示されている状態でユーザーがヘルプツアーを開始した時、**When** 「バッジのカスタマイズ」ステップに進むと、**Then** 「デザイン・表示設定」タブの表示が維持されたまま「バッジ設定」エリアが正しくハイライトされる。
3. **Given** ウィンドウの高さやスクロール位置により「バッジ設定」エリアが現在の表示領域外にある時、**When** 「バッジのカスタマイズ」ステップに進むと、**Then** 対象環境カードの環境名およびタブ一覧が画面上端から隠れないスクロール量で「バッジ設定」エリアが視認可能な位置まで自動スクロールされた上でハイライト表示される。

---

### User Story 2 - ツアー進行方向（進む・戻る）に応じた対象タブの双方向連動 (Priority: P1)

ユーザーがヘルプツアー内でウェルカムステップから先に「URLパターンの設定」ステップへ進み、続いて「バッジのカスタマイズ」ステップへ進んだ場合、または後続のステップから「戻る」操作によって前のステップへ戻った場合、それぞれのステップが案内する設定項目が配置されているタブへ自動的に切り替わる。これにより、順方向・逆方向のどちらに移動しても常に正しい設定項目へフォーカスが維持され、タブのつながりを把握しながら設定の流れを理解できる。

**Why this priority**: デフォルトタブである「URLパターン」から順を追って「バッジのカスタマイズ」へ進む自然な順序としつつ、どちらのステップも別々のタブに分かれているため、進む・戻るのいずれの方向でも常に正しいタブとフォーカスが保たれる必要があるため。

**Independent Test**: ヘルプツアーでウェルカム →「URLパターンの設定」→「バッジのカスタマイズ」→ 後続ステップの間を「次へ」と「戻る」で往復移動し、「URLパターンの設定」では「URLパターン」タブ内のURL設定エリアが、「バッジのカスタマイズ」では「デザイン・表示設定」タブ内のバッジ設定が毎回ハイライトされることで独立して検証できる。

**Acceptance Scenarios**:

1. **Given** ウェルカムステップを表示中、または「URLパターンの設定」ステップを表示中で「URLパターン」タブが開かれている時、**When** ユーザーが「次へ」を選択して「バッジのカスタマイズ」ステップへ進むと、**Then** 対象環境カードが「デザイン・表示設定」タブへ自動的に切り替わり、「バッジ設定」エリアがハイライトされる。
2. **Given** 「バッジのカスタマイズ」ステップを表示中で「デザイン・表示設定」タブが開かれている時、**When** ユーザーが「戻る」を選択して「URLパターンの設定」ステップへ戻ると、**Then** 対象環境カードが「URLパターン」タブへ再び切り替わり、URLパターンの入力・一覧エリアがハイライトされる。
3. **Given** ユーザーが「バッジのカスタマイズ」以降のステップ（URLチェッカー等）に進んだ後、**When** 「戻る」操作で「バッジのカスタマイズ」ステップへ戻ると、**Then** 当該ステップ実行前のタブ状態に関わらず「デザイン・表示設定」タブが表示され、「バッジ設定」エリアがハイライトされる。

---

### User Story 3 - ツアー完了・中断後の閲覧状態復元と操作復帰 (Priority: P2)

ユーザーがヘルプツアーを最後まで完了した場合、または途中で中断（閉じる操作）した場合、ツアー中の自動タブ切替によってユーザーがもともと見ていたタブ状態が失われないよう、ツアー開始前に選択していたタブ状態へ戻される。また、ツアー終了後は即座に設定項目の編集やタブ切替などの通常操作を行える状態に戻る。

**Why this priority**: ツアー中の自動タブ切替がユーザーの元の作業コンテキストを上書きしたままにせず、オンボーディング体験から実際の設定作業へ自然に繋げるため。

**Independent Test**: 特定のタブを選択した状態でヘルプツアーを開始し、完了操作および途中終了操作の双方を行った後、開始前に開いていたタブに戻り、通常の入力やタブ操作が可能であることを確認することで独立して検証できる。

**Acceptance Scenarios**:

1. **Given** ユーザーが対象環境カードで「URLパターン」タブを開いた状態でヘルプツアーを開始した時、**When** 「バッジのカスタマイズ」ステップを経由してツアーを途中で終了すると、**Then** 対象環境カードはツアー開始前の「URLパターン」タブに戻り、オーバーレイが残らず通常操作が可能になる。
2. **Given** ユーザーが対象環境カードで「デザイン・表示設定」タブを開いた状態でヘルプツアーを開始した時、**When** 最後までツアーを完了すると、**Then** 対象環境カードはツアー開始前の「デザイン・表示設定」タブに戻り、ユーザーがそのまま作業を続けられる。

---

### Edge Cases

- ツアー開始時にどの環境カードのタブが開かれているかに依存せず、案内対象となる本番環境カードのタブ状態のみがツアーの各ステップに合わせて制御される。
- タブ切替直後の表示更新が完了する前にハイライト枠の位置・サイズ計算が走らないよう、表示が反映された正しい位置・大きさでフォーカス枠が描画される。
- ユーザーがツアーの連続クリックやキーボード操作で素早くステップを行き来した場合でも、直近のステップに対応するタブとフォーカス表示が崩れずに追従する。
- ツアーの実行中に強制終了または再開始が行われても、二重起動や古い状態の残留によってタブが誤った状態に切り替わらない。
- 画面幅が狭い場合（狭いウィンドウ表示）、ライトモード／ダークモードのどちらのテーマ、および日本語／英語のどちらの表示言語であっても、タブ切替後のハイライト枠と案内吹き出しが正しく視認できる。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、ヘルプツアーの「バッジのカスタマイズ」ステップを表示する際、対象環境（本番環境）カードのタブを「デザイン・表示設定」タブへ自動的に切り替えなければならない（MUST）。
- **FR-002**: システムは、「バッジのカスタマイズ」ステップにおいて、「デザイン・表示設定」タブ内の「バッジ設定」エリア（バッジの文字、文字色、枠線色を含む項目群）をフォーカス対象としてハイライトし、案内吹き出しを適切な位置に表示しなければならない（MUST）。
- **FR-003**: システムは、ヘルプツアーの「URLパターンの設定」ステップを表示する際、対象環境（本番環境）カードのタブを「URLパターン」タブへ自動的に切り替え、URLパターンの設定エリアをフォーカス対象としてハイライトしなければならない（MUST）。
- **FR-004**: システムは、ヘルプツアーの「次へ」および「戻る」を含むあらゆるステップ遷移において、各ステップが対象とするタブが表示された状態でハイライト枠の位置およびサイズを算出しなければならない（MUST）。
- **FR-005**: システムは、環境カード内のステップへ移動して自動スクロールを行う際、対象の設定エリアが視認でき、かつ親カードのタブ一覧（および可能な限り環境名ヘッダー）が画面上端から隠れない位置にスクロール量を抑えなければならない（MUST）。
- **FR-006**: システムは、ヘルプツアーにおける紹介順序を「URLパターンの設定」を先、「バッジのカスタマイズ」を後として案内しなければならない（MUST）。
- **FR-007**: システムは、ヘルプツアーの完了時および途中終了時に、対象環境カードの選択タブをツアー開始前にユーザーが選択していたタブ状態へ復元しなければならない（MUST）。
- **FR-008**: システムは、ライト／ダークの両テーマおよび日本語／英語の両表示言語において、タブ切替後のハイライト表示と案内吹き出しの視認性を損なってはならない（MUST NOT）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ヘルプツアーにおける「バッジのカスタマイズ」および「URLパターンの設定」の両ステップにおいて、100%のケースで対象の設定エリアにフォーカス枠が一致し、案内吹き出しが画面中央への孤立表示にならず対象付近に表示される。
- **SC-002**: ツアー開始から完了まで（「次へ」および「戻る」によるタブをまたいだ往復移動を含む）、ユーザーが手動でタブを切り替える必要回数（0回）で、すべての案内対象項目を途切れなく確認できる。
- **SC-003**: タブ切替を伴うステップ遷移において、1秒以内に対象タブの表示とハイライト枠の配置が完了し、位置ずれや枠の欠けが発生しない。
- **SC-004**: ツアーの完了または中断後、100%のケースでツアー開始前のタブ表示状態が復元され、直ちに全設定項目の編集操作を再開できる。

## Assumptions

- ヘルプツアーで環境設定の例示対象となるカードは、現行仕様通りデフォルトの「本番環境」カードとする。
- 「バッジのカスタマイズ」ステップでは、案内文言（「バッジの文字（4文字以内）や色は自由に変えられます」）と一致させるため、「デザイン・表示設定」タブ内の「バッジ設定」エリア（文字・文字色・枠線色）をフォーカス対象とし、機能トグル群は対象範囲に含めない。
- ツアー終了（完了または途中中断）時は、ユーザーがツアー開始前に開いていたタブ状態へ戻すことを標準の振る舞いとする。
- ヘルプツアーのステップ総数（全7ステップ）および各ステップの案内タイトル・説明文言（多言語辞書）は現行仕様を維持し、対象カード内のステップ順を「URLパターンの設定」→「バッジのカスタマイズ」とする。
