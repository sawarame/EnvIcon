# クイックスタート検証ガイド (Quickstart): ヘルプツアー「バッジのカスタマイズ」タブ連動修正

**Feature Branch**: `004-fix-tour-badge-focus` | **Date**: 2026-11-16

実装完了後に本機能要件（[spec.md](./spec.md)）が満たされていることを検証するための手順書です。

## 1. 事前準備・ビルド検証ゲート

プロジェクトルートで以下を実行し、TypeScript の型エラー・Webpack バンドルエラーがないことを確認します。

```bash
npm run build
```

- **期待結果**: コマンドが終了コード `0` で完了し、`package/js/` および `package.zip` がエラーなく生成されること。

## 2. Chrome 拡張機能への読み込み

1. Chrome で `chrome://extensions/` を開く。
2. 右上の「デベロッパーモード」を ON にする。
3. 「パッケージ化されていない拡張機能を読み込む」からリポジトリ配下の `package/` ディレクトリを読み込む（既に読み込み済みの場合はリロードアイコンをクリック）。
4. 拡張機能の「オプション」ページを開く。

## 3. エンドツーエンド手動検証シナリオ

### シナリオ A: 初期状態（URLパターンタブ表示中）からのヘルプツアー完走（US1, US2, US3）

1. オプション画面を開き、本番環境（`PROD`）カードのタブがデフォルトの「URLパターン」になっていることを確認する。
2. ヘッダーのヘルプ（`?`）アイコンをクリックしてツアーを開始する。
3. **Step 1（EnvIconへようこそ！）**: 中央にウェルカムモーダルが表示されることを確認し、「次へ」をクリック。
4. **Step 2（URLパターンの設定）**:
   - 本番環境カードが「URLパターン」タブを表示しており、環境名ヘッダーとタブ一覧（「URLパターン」「デザイン・表示設定」）が画面上端から隠れずに見えていること。
   - URLパターン入力エリア（先頭行の入力グループ）がハイライトされ、案内ツールチップが表示されること。
5. 「次へ」をクリックし、**Step 3（バッジのカスタマイズ）** へ進む。
   - 本番環境カードが自動的に**「デザイン・表示設定」タブに切り替わる**こと。
   - タブ一覧（「URLパターン」「デザイン・表示設定」）と環境名ヘッダーが画面内に見えたままのスクロール量で、「バッジ設定」エリア（バッジの文字・バッジの色・バッジのフチドリ色）が白い枠で正確にハイライトされ、その直下に案内ツールチップが表示されること。
6. そのまま「完了」まで「次へ」で進め、Step 4（設定をテスト）・Step 5（カスタム環境を追加）・Step 6（自動保存）・Step 7（最後に）が従来どおりフォーカス・表示されること。
7. 「完了」をクリックするとツアーが閉じ、本番環境カードのタブが開始前の**「URLパターン」タブのまま**であり、通常編集が可能であること。

### シナリオ B: 「戻る」操作によるタブをまたいだ往復移動（US2）

1. 本番環境カードでツアーを開始し、Step 3（バッジのカスタマイズ）まで進む。
2. ツールチップの「戻る」をクリックする。
   - 本番環境カードが再び**「URLパターン」タブに切り替わり**、タブ一覧が見えた状態で URL パターン入力エリアにハイライト枠がズレなく表示されること。
3. 再度「次へ」で Step 3 へ進み、さらに「次へ」で Step 4（URLチェッカー）へ進む。
4. Step 4 から「戻る」をクリックする。
   - 「デザイン・表示設定」タブが選択され、タブ一覧が見えた状態で「バッジ設定」エリアがハイライトされること。

### シナリオ C: 「デザイン・表示設定」タブ表示中からのツアー開始と途中中断（US1, US3）

1. 本番環境カードの**「デザイン・表示設定」タブを手動で開いた状態**にする。
2. ヘルプアイコンからツアーを開始し、Step 2（URLパターンの設定）→ Step 3（バッジのカスタマイズ）へ進む。
   - Step 2 では「URLパターン」タブへ自動で切り替わってハイライトされ、Step 3 では「デザイン・表示設定」タブへ切り替わって「バッジ設定」がハイライトされることが確認できる。
3. Step 2 の状態でツールチップ右上の閉じるボタン（`×`）または `Esc` キーでツアーを中断する。
   - 本番環境カードのタブがツアー開始前の**「デザイン・表示設定」タブに復元**されること。

### シナリオ D: テーマ・言語・画面幅の互換性確認（Edge Cases）

1. 設定画面ヘッダーの言語切り替えで「English」および「日本語」、テーマ切り替えで「ダークモード」および「ライトモード」を切り替えてシナリオ A の Step 2〜3 を確認する。
2. ウィンドウ幅を狭めた状態（例: 680px 程度）でも、タブ切替後の「バッジ設定」エリアのハイライト枠とツールチップが見切れずに表示されること。
3. 確認後、もし意図せず `tutorialCompleted` が保存された状態で初回自動起動を再テストしたい場合は、オプション画面の DevTools Console で `chrome.storage.local.remove('tutorialCompleted')` を実行しページをリロードして、自動起動ツアーでも同様に動作することを確認する。
